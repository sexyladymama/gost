# Repository workflow

The user has explicitly requested that code changes be published to GitHub after each completed change.

- Run the checks relevant to the change, then commit and push your own changes to the current working branch on `origin`.
- Do not include unrelated changes made by the user or another agent.
- Do not force-push, rewrite shared history, or merge into another branch without an explicit request.
- Report the pushed commit or branch link. If publishing fails, state that clearly; never claim local changes are on GitHub.
